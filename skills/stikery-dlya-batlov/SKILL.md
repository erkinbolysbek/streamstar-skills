# Стикеры для батлов по фото стримера

Стикеры показывают на экране во время батла: "Спасибо!", "Ещё чуть-чуть!", "Мы победили!". Свой мультяшный персонаж с лицом стримера узнаётся лучше чужих картинок.

Этот скил не рисует сам. Он собирает точный промпт, который стример вставляет в любую нейросеть для картинок, умеющую работать с фото (например ChatGPT, Gemini, Midjourney и похожие).

## Что спросить у стримера

1. Пол и примерный возраст персонажа.
2. Волосы: цвет, длина, причёска. Борода, очки, пирсинг, если есть.
3. В чём обычно стримит (худи, футболка, цвет).
4. Стиль: 3D как в мультфильмах, плоский яркий, аниме, другой.
5. Какие надписи нужны. Если не знает, предложи набор из списка ниже.

Попроси приложить к нейросети своё фото анфас при хорошем свете.

## Набор надписей по умолчанию

- Спасибо!
- Ещё чуть-чуть!
- Мы победили!
- Не сдаёмся!
- Вперёд!
- Красавчики! / Красотки!
- Последние 10 секунд!
- Поддержите!

## Шаблон промпта

Подставь ответы стримера в скобки и выдай один промпт на каждый стикер.

```
Сделай квадратный стикер 1:1 по моему фото.
Персонаж: мультяшная версия человека с фото, [пол], [возраст], [волосы], [особенности], одет в [одежда].
Стиль: [стиль], яркие насыщенные цвета, чёткий контур, как наклейка.
Эмоция и поза: [эмоция под надпись, например "радостно поднимает руки вверх"].
Надпись крупными буквами на русском: "[текст]". Шрифт жирный, читается на маленьком экране телефона, без ошибок в словах.
Фон: [однотонный цвет или прозрачный], без мелких деталей.
Сохранить узнаваемость лица с фото.
```

## Подсказки для стримера

- Нейросети часто ошибаются в русских буквах. Если надпись кривая, попроси нейросеть перерисовать только текст или добавь надпись потом в любом редакторе.
- Делай все стикеры в одном чате с нейросетью, тогда персонаж выйдет одинаковым.
- Проверь стикер на телефоне в маленьком размере: если надпись не читается, увеличь её.
- Используй только своё фото или фото человека, который дал согласие.

## Как отвечать

Сначала задай вопросы, которых не хватает. Потом выдай готовые промпты по одному на стикер, пронумерованные, чтобы их можно было копировать по очереди.
