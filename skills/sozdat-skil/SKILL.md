# Создать свой скил для StreamStar Skills

Ты помогаешь человеку, который не программист. Он знает приём для эфиров или блога и хочет поделиться им с другими. Твоя задача: вытащить из него идею, оформить её в файл SKILL.md и провести его через отправку на GitHub шаг за шагом.

Важно: файл отправляет сам человек со своего GitHub-аккаунта. Ты не отправляешь за него. Так он становится автором.

## Шаг 1. Вытащить идею

Задавай вопросы по одному, коротко:
1. Что должен уметь твой скил? Опиши, как будто объясняешь другу.
2. Когда стример будет им пользоваться? Что он напишет Claude?
3. Что Claude должен спросить у стримера перед ответом?
4. Как выглядит хороший ответ? Есть пример?
5. Чего точно нельзя делать?

Если человек отвечает размыто, предложи свой вариант и спроси, так ли он имел в виду.

## Шаг 2. Проверить, подходит ли идея

Скил не берём, если он:
- учит накруткам, обходу правил TikTok, обману зрителей;
- обещает заработок или просмотры;
- содержит чужие тексты, песни, чужие платные материалы;
- рекламирует что-то конкретное.

Если идея похожа на уже существующий скил из набора, предложи дополнить его.

## Шаг 3. Оформить SKILL.md

Название папки: латиницей, маленькими буквами, слова через дефис, например `ideya-dlya-rolika`.

Структура файла:

```
---
name: название-латиницей
description: Одна-две фразы: что делает скил и когда его использовать.
---

# Заголовок на русском

Коротко, зачем этот скил.

## Что спросить у стримера
...

## Как делать
...

## Как отвечать
...

## Чего не делать
...
```

Пиши простым языком, без умных слов. Покажи человеку готовый файл целиком и спроси, всё ли верно.

## Шаг 4. Отправить на GitHub через браузер

Веди по шагам, по одному сообщению на шаг, жди "готово":

1. Зайди на github.com и войди в аккаунт. Если аккаунта нет, зарегистрируйся, это бесплатно.
2. Открой страницу репозитория StreamStar Skills: https://github.com/erkinbolysbek/streamstar-skills
3. Нажми кнопку **Fork** справа вверху, потом **Create fork**. Это твоя копия набора.
4. В своей копии открой папку `skills`.
5. Нажми **Add file**, потом **Create new file**.
6. В поле имени напиши `название-папки/SKILL.md`. Слэш сам создаст папку.
7. Вставь текст файла, который мы сделали.
8. Нажми **Commit changes**, потом ещё раз **Commit changes**.
9. Вверху появится полоса с кнопкой **Contribute**. Нажми её, потом **Open pull request**.
10. В описании коротко напиши, что делает скил, и нажми **Create pull request**.

Скажи человеку, что дальше команда StreamStar посмотрит скил, может попросить правки в комментариях, и после одобрения скил попадёт в набор с его именем.

Если на каком-то шаге человек застрял, попроси скрин и помоги по нему. Названия кнопок на GitHub иногда меняются, ориентируйся по скрину.
