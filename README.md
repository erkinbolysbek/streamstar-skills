# StreamStar Skills

Бесплатный набор ИИ-помощников для стримеров и блогеров TikTok. Работает в Claude: ставишь скил, пишешь своими словами, что нужно, и получаешь готовый результат.

Набор делает команда [StreamStar](https://www.tiktok.com/t/ZSgQv17qv/), официального агентства TikTok. Всё на русском, без накруток и без обещаний лёгких денег.

## Что внутри

| Скил | Что делает |
|---|---|
| `razbor-shapki` | Разбирает шапку профиля и пишет новую: имя, описание, ссылка, закрепы |
| `menu-pozhelaniy` | Составляет меню пожеланий для эфира: что ты делаешь за подарки |
| `stikery-dlya-batlov` | Готовит промпты для нейросети: стикеры для батлов с твоим лицом |
| `podgotovka-k-batlu` | План батла и фразы для эфира: до, во время, после |
| `itogi-efira` | Разбирает цифры прошедшего эфира и даёт план на следующий |
| `tikfinity-nastroyka` | Помогает придумать и настроить интерактив через TikFinity |
| `sozdat-skil` | Помогает сделать свой скил и добавить его в этот набор |

## Как поставить

### В приложении Claude (сайт, телефон, компьютер)

1. Открой страницу [Releases](../../releases) этого репозитория.
2. Скачай zip-архив нужного скила, например `razbor-shapki.zip`.
3. В Claude открой настройки, найди раздел со скилами (Skills) и загрузи этот архив.
4. Включи скил и напиши в чат, например: "разбери шапку моего профиля" и приложи скрин.

Скилы на телефоне можно поставить, если у тебя в аккаунте Claude доступны скилы. Если раздела нет, поставь с компьютера через сайт claude.ai.

### В Claude Code

```
/plugin marketplace add erkinbolysbek/streamstar-skills
/plugin install streamstar-skills@streamstar-skills
```

## Как добавить свой скил

Знаешь приём, который работает на твоих эфирах? Добавь его в набор, и твоё имя будет в списке авторов.

Программировать не нужно. Поставь скил `sozdat-skil` и напиши Claude: "хочу сделать скил". Он задаст вопросы, оформит файл и проведёт тебя через отправку на GitHub по шагам.

Подробно всё написано в [CONTRIBUTING.md](CONTRIBUTING.md).
