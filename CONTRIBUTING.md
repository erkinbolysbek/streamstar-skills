# Как добавить свой скил

Скил это обычный текстовый файл с инструкцией для Claude: что спросить у стримера, как делать и как отвечать. Программировать не нужно.

## Самый простой путь: через помощника

1. Поставь скил `sozdat-skil` (как ставить, написано в README).
2. Напиши Claude: "хочу сделать скил".
3. Отвечай на вопросы. Claude сам оформит файл и проведёт тебя по шагам на GitHub.

## Если хочешь сам

### 1. Аккаунт на GitHub

Зарегистрируйся на [github.com](https://github.com), это бесплатно.

### 2. Сделай свою копию набора

Открой этот репозиторий и нажми **Fork** справа вверху, потом **Create fork**.

### 3. Создай файл скила

1. В своей копии открой папку `skills`.
2. Нажми **Add file**, потом **Create new file**.
3. В поле имени напиши `nazvanie-skila/SKILL.md`. Название латиницей, маленькими буквами, слова через дефис.
4. Вставь текст по шаблону ниже.
5. Нажми **Commit changes** два раза.

### 4. Отправь на проверку

Вверху своей копии нажми **Contribute**, потом **Open pull request**, коротко опиши скил и нажми **Create pull request**.

Команда StreamStar посмотрит. Если нужны правки, напишем в комментариях к твоему pull request. Когда скил примут, добавим тебя в AUTHORS.md.

## Шаблон SKILL.md

```
---
name: nazvanie-skila
description: Одна-две фразы: что делает скил и когда его использовать.
---

# Заголовок на русском

Коротко, зачем этот скил.

## Что спросить у стримера

## Как делать

## Как отвечать

## Чего не делать
```

## Какие скилы принимаем

Берём:
- приёмы для эфиров, роликов, профиля, батлов, общения со зрителями;
- то, что ты сам проверил на своих эфирах;
- простой язык, понятный новичку.

Не берём:
- накрутки, обход правил TikTok, обман зрителей;
- обещания заработка и просмотров;
- чужие тексты, песни и платные материалы;
- рекламу конкретных товаров и сервисов;
- всё, что вредит здоровью стримера или унижает людей.

## Правила

- Один pull request, один скил.
- Пиши на русском. Скилы на казахском, узбекском и других языках тоже берём, просто добавь в конец названия язык, например `razbor-shapki-kz`.
- Уважай других авторов в комментариях.
